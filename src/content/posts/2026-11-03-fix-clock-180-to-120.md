commit 9f3e1a7c
Author: owner <owner@latitude>

    fix(clock): 180 -> 120

    Estonia left summer time. Dashboard clock did not.
    Settings menu has no "Set time".
    Previous owner said changing the clock needs the nav SD card.

    - Pressed every button, searched the web (1h)
    - Reversed firmware: Settings menu is defined on the SD card
    - Blank SD card rejected by DRM
    - Legit SD card: 60 EUR with shipping. Declined
    - Modified ext3 update image: rejected, signature check
    - Built QEMU target, custom 2.6 kernel, CAN bus emulator
    - Patched out reboot syscalls (unit rebooted every 3s)
    - Reversed ttn, which parses master.script
    - SHEX: one token, no args. Dead end
    - Fuzzed image decoders. Dead end
    - LOG path traversal -> core_pattern -> payload script
    - Crashed /bin/dbus-monitor (no bus running); coredump
      handler ran payload as root
    - dd'd the eMMC
    - Found /mnt/flash/settings.dat. Offset stored in minutes

    Previous owner was right.

     settings.dat | 2 +-
     1 file changed, 1 insertion(+), 1 deletion(-)

    Revert scheduled: 2027-03-28
